AI Stop Slop

Privacy Policy

Effective date: September 25, 2026

AI Stop Slop does not collect, store, or transmit any personal data. All image analysis runs entirely inside your browser.

1. Overview

AI Stop Slop ("the Extension") is a Google Chrome extension that detects AI-generated images on web pages and marks them with a visible badge. This Privacy Policy explains what data the Extension accesses, how it is used, and what is never done with it.

2. Data the Extension accesses

Data Purpose Sent externally?
Image URLs on the current page Checked against a list of known AI image service patterns (heuristic detection) Never
Image files on the current page Downloaded from the same server the page already loads them from, then analysed inside your browser: embedded provenance metadata (C2PA / IPTC, AI generator parameters, camera EXIF) and — only if you enable the experimental option — colour and edge statistics Never
Neural network model (optional feature, off by default) When you enable it, a 190 MB image-classifier file is downloaded once from the project's GitHub Releases page, checked against a fixed SHA-256 checksum and stored in the browser's Cache Storage. Images are classified locally with it. Deleting the model or turning the feature off removes it from memory; "Delete downloaded model" removes the file. Never (nothing is uploaded; the download itself contains no user data)
Image alt text, title and caption Scanned locally for AI-related keywords Never
Extension settings (enabled state, sensitivity, image size threshold) Stored in chrome.storage.sync to persist user preferences across devices Never (synced by Chrome, not the Extension)
Analysis results per image URL (cache) Stored in chrome.storage.local for 24 hours to avoid reanalysing the same image Never

3. What the Extension does NOT do

  • Does not collect or transmit browsing history, URLs visited, or page content.
  • Does not upload image data to any server or third-party service.
  • Does not use analytics, crash reporting, or telemetry of any kind.
  • Does not display advertisements.
  • Does not create user accounts or require authentication.
  • Does not communicate with any server other than the image hosts a page already uses — and only to download those same images for local analysis. Nothing is sent to the developer.

4. Permissions explained

Permission Why it is needed
storage Saves user settings and local analysis cache. No personal data is stored.
Host access to all sites (<all_urls>) Images are usually served from other domains (CDNs), and browsers block extensions from reading them inside the page. This permission lets the Extension download a page's images to check their metadata locally. Requests carry no cookies.
offscreen Runs the optional neural classifier in a hidden extension page, which (unlike the service worker) can use multiple CPU threads.
Content script on all URLs (<all_urls>) The Extension must run on every page to automatically detect AI images as the user browses. No data is read from pages beyond image elements and their associated text.

5. Local storage

The Extension stores two categories of data locally on your device:

  • Settings — your preferences (on/off toggle, sensitivity threshold, minimum image size). Synced across your Chrome profile via Google's own sync infrastructure.
  • Analysis cache — a mapping of image URL hashes to detection results, kept for 24 hours to improve performance. You can clear this at any time via the Settings page inside the Extension.

Neither category contains personal information.

6. Third-party services

The Extension does not integrate with, contact, or share data with any third-party service, API, or analytics platform.

7. Children's privacy

The Extension does not knowingly collect any information from anyone, including children under the age of 13.
